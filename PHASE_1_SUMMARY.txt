================================================================================
KEY DECISIONS
================================================================================

1. JEST OVER KARMA ✅
   - 2-3x faster test execution
   - No browser spawning overhead
   - Built-in mocking and coverage
   - Better developer experience
   - Industry standard for modern JavaScript

2. MODULAR ARCHITECTURE ✅
   - Core services (protocols, config)
   - Features (UI/UX per feature)
   - Shared components (reusable)
   - Clean separation of concerns

3. TYPESCRIPT STRICT MODE ✅
   - Catches errors at compile time
   - Forces explicit null handling
   - Improves code maintainability
   - Reduces runtime bugs

4. ENGLISH CODE, PORTUGUESE DOCS ✅
   - Code: Variables, functions, classes in English
   - Docs: Guides, READMEs in Portuguese-BR
   - Consistency across codebase
   - International collaboration ready

5. CAPACITOR OVER CORDOVA ✅
   - Modern, actively maintained
   - Better performance
   - Simpler plugin API
   - Android/iOS support
